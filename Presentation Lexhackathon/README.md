# Presentation Lexhackathon

Презентация команды Lexab для LexHackathon 2026 (Министерство юстиции Республики Узбекистан, 20–22 ноября 2026).

Lexab jamoasining LexHackathon 2026 uchun taqdimoti (Oʻzbekiston Respublikasi Adliya vazirligi, 2026-yil 20–22-noyabr).

## Открыть с анимациями / Animatsiyalar bilan ochish

- Русский: https://imranprodead-cell.github.io/Lexab/Lexab-RU.html
- Oʻzbekcha: https://imranprodead-cell.github.io/Lexab/Lexab-UZ.html

Управление: стрелки, пробел или клик листают слайды, F включает полный экран, L переключает русский и узбекский.

Boshqaruv: strelkalar, probel yoki bosish slaydlarni almashtiradi, F toʻliq ekranni yoqadi, L rus va oʻzbek tilini almashtiradi.

Файлы можно и скачать: шрифты, скриншоты и анимации встроены в сам файл, он открывается в любом браузере.
